## 二、逐页设计数据实录

### 2.1 首页 `/`
- 纯白底；**超大黑体标语「DESIGN EVERYDAY.」** 两行占满左半屏，句号收尾
- 2–3 个**高饱和黄色大圆**错落（其中一个被竖条纹理"融化"——融球教程的静态预告）
- 顶部极小 mono 站名；底部**胶囊导航条**（见 2.12）
- 布局语言：上下轻、中间重，元素靠位置对话，不画分隔线

### 2.2 设计导航 `/designwebsite/`
- H1「设计导航:寻找你的需求」**64px / 400**
- **80 张图**——以图代文的外部设计站推荐目录
- 色彩：`#111111`×198、`#333333`、`#b0b0b0`、暖白 `#f4f3f1`×19
- 学：**资源目录页 = 大图网格 + 几乎无装饰**，让图自己说话

### 2.3 新手入门 `/answer/`
- H1「我该如何了解平面设计？」**52.3px / 600，薄荷白 rgb(241,254,251)**
- **淡薄荷面板 rgb(228,239,235) ×93**——整页彩色底
- 学：问答页 = 彩底 + 大字问答，**薄荷色系是站点的"教学"主题色**

### 2.4 学习工程端口 `/ignoredone-project/`
- H1「学习工程端口」40px / 600；薄荷白 ×82
- 学：工程页标题用「端口」这种**系统词汇**——把栏目命名成 OS 术语（v2 已在用：档案阵列/作战记录）

### 2.5 图文教程终端 `/article-arrangement/`
- H1「图文教程终端」40px / 600；11 图；薄荷系
- 学：教程列表保持同一彩底性格，形成板块一致性

### 2.6 作品库 `/portfolio/`
- H1「委托封面作品」40px / 600；**70 图**（委托封面 2560px webp）
- 色彩几乎全 `#111`（图片本身占满视觉）
- 学：作品页**零 UI 存在感**——图片是唯一主角

### 2.7 学方舟做设计 `/graphic-design-arknights/`
- H1「学方舟做设计」**64px / 400**；导语 29.6px Instrument Sans 薄荷白
- 学：核心栏目用最大号轻字重标题（与首页同级的排版礼遇）

### 2.8 / 2.9 资源系统两页 `/arknights_design/` `/endfield_design/`
- 双 H1 均 **64px / 400**（「明日方舟美术资源系统」「终末地美术资源系统」）
- 薄荷家族持续；终末地页出现 **#11141a 深蓝黑**（终末地的品牌暗色）
- 学：**姊妹栏目用同构排版、不同内容色**——方舟=薄荷，终末地=深蓝黑

### 2.10 IgnoBoard `/ignoboard/`
- H1「IgnoBoard」**88px / 700**（全站最大最重——因为它是"产品页"）
- 色彩：**#0071E3（苹果蓝）×53、#1d1d1f、#86868b、白色 65% 透明**
- 学：**这是全站唯一换整套配色语言的页面**——留言板做成苹果风产品页。
  → 结论：**每个板块可以有自己的"主题皮肤"**，站级色板只是默认值

### 2.11 封面设计库 `/coverdesign/`
- H1 64px/400；封面图 2560px webp；涂墨作战、白H17-4 等
- 学：**封面即内容**，图 2560px 起步

### 2.12 底部胶囊导航（用户截图参照）
- 一个**黄色有机大底**（blob 形）托着胶囊按钮组
- 每个胶囊：**白色圆底 → 当前项整颗填充黄色**，圆角全圆，文字 16.8px
- 胶囊按钮之间 8-12px 间距，整体贴住 blob 边缘

## 三、设计系统提炼

### 3.1 色彩系统（实测汇总）

| 角色 | 值 | 出现位置 |
| --- | --- | --- |
| 基底 | `#FFFFFF` | 全站 |
| 墨色 | `#111111` / `#333333` / `#666666` / `#b0b0b0` | 文字四级灰阶 |
| 暖白 | `#f4f3f1` | 卡片底 |
| **薄荷面板** | `#e4efeb` | 新手入门/学习工程/教程/资源系统页 |
| **薄荷白** | `#f1fefb` | 彩底上的文字 |
| **主题黄** | 高饱和黄（≈#FFE01A 系） | 首页几何、导航激活胶囊 |
| **苹果蓝** | `#0071E3` | IgnoBoard 专属 |
| 苹果灰 | `#1d1d1f` / `#86868b` | IgnoBoard 文字 |

**核心结论：色板是「白底 + 四级灰阶 + 每板块一个主题色」**。主题色之间互不同族（黄/薄荷/苹果蓝），靠"每页只用一套"保持统一。

### 3.2 字体阶梯（实测）

| 级别 | 字号/字重 | 用途 |
| --- | --- | --- |
| L0 | **88px / 700** | 产品页 hero（IgnoBoard） |
| L1 | **64px / 400** | 首页标语、核心栏目标题 |
| L2 | 52px / 600 | 问答页标题 |
| L3 | 40px / 600 | 工程端口/作品库标题 |
| L4 | 29.6px | 分类导语 |
| L5 | 16.8px / 400→600 | 导航胶囊、页脚小标 |
| 正文 | Jost（几何人文无衬线） | 全站 |
| 标题族 | Instrument Sans | 大标题 |

**规则**：字号越大字重越轻（L1 是 400），越小的 UI 字越重。这个"倒挂"是高级感来源。

### 3.3 按键/胶囊规范（从截图 + DOM）

- 形状：**全圆胶囊**（border-radius: 999px）
- 默认：白底 + 墨字（无边框，靠阴影/底色区分）
- 激活：**整颗填充主题色**，文字转深色/白
- 容器：胶囊组坐在一个**有机 blob 形彩色底**上
- 尺寸：padding ≈ 10px 20px；间距 8–12px；字号 16.8px

### 3.4 体验与分区

- 每个板块 = 独立彩底着陆段（hero 彩底 → 内容白底），色彩性格清晰
- 图片页零 UI 存在感；文字页排版礼遇最高
- WordPress 全 block 布局 → 分区间距大而均匀（约 96px 级）

### 3.5 动效词汇

融球（metaball）、螺旋扩散、毛玻璃音波、双螺旋——**软性有机**；导航胶囊的激活切换是**颜色填充过渡**（非位移）。

## 五、风格边界（不抄清单）

- 板块主题色限定在**蓝紫-靛-蓝-青同系家族**（v2 品牌一致性优先；ignoredone 是黄/薄荷/苹果蓝跨族，因为他们没有站级品牌色约束）
- 侧栏信息架构保留（Claude 壳），不搬它的底部胶囊导航条位置——但**胶囊样式语言**全盘吸收
- 88px/700 的 L0 级留给未来"产品页"（若做作品展示页）
